# Levantamento de Requisitos

Nesta pasta está o documento em PDF com o levantamento de requisitos do sistema de marketplace.

## O que tem aqui

- Requisitos funcionais (RF)
- Requisitos não funcionais (RNF)
- Regras de negócio
- Pesquisa de sistemas similares
- Ideias adicionais (brainstorm)
- Análise de valor do projeto

## Objetivo

Organizar e descrever os requisitos do sistema, servindo como base para o desenvolvimento e entendimento do projeto.
